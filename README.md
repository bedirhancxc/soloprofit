# SoloProfit

Free browser-based business calculators.

## Deployment
In repository **Settings > Pages**, select **GitHub Actions** as the source. The workflow tests on every push and deploys on successful push to main. A scheduled daily run checks source files but does not deploy or create content.

Expected URL after successful deployment: https://bedirhancxc.github.io/soloprofit/

## Local testing
Run `python3 scripts/check_site.py`, then open `index.html` in a browser.

Analytics, payments, ads, and autonomous AI operation are not configured yet.
